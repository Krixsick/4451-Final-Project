# Real NBA preparation walkthrough

This is an actual cached NBA subset for the detailed English notebook. It includes
Scottie Barnes's first 14 appearances in 2024-25, his birthdate, all league team
games through his last included appearance, and date-filtered advanced snapshots.
Keeping complete team history is necessary to reconstruct rest and verify GP;
using only games in which the example player appeared would be incorrect.

The expected clean rows are the matching subset of the official league-wide
prepared season. Ten early appearances are excluded because ten previous
appearances are required. Four rows remain. File and original cache hashes are
recorded in walkthrough_manifest.json. No NBA download is needed to run this
example. It is a teaching subset, not the model-training or evaluation dataset.
The official experiment remains a global model across eligible NBA players.
